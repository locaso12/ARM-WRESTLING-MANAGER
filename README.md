
 ARM-WRESTLING-MANAGER

 Descripción

ARM-WRESTLING-MANAGER es una aplicación móvil diseñada para la gestión y administración de torneos de pulso deportivo.

El sistema permite registrar competidores, generar llaves de competencia y administrar torneos mediante las modalidades de Eliminación Directa y Doble Eliminación.

Inspirado en plataformas como BracketHQ, el proyecto adapta estas funcionalidades al entorno móvil Android.

---

 Objetivo

Automatizar la organización de torneos de pulso deportivo mediante una aplicación fácil de utilizar y accesible desde dispositivos móviles.

---

 Características

- Registro de competidores.
- Creación de torneos.
- Eliminación directa.
- Doble eliminación.
- Gestión de resultados.
- Generación automática de brackets.
- Determinación de campeones.
- Historial de torneos.
