 Casos de Uso

 Caso de Uso 1: Registrar Competidor

 Actor
Administrador

 Descripción

Permite registrar un nuevo participante en el sistema.

 Flujo Principal

1. Seleccionar opción "Registrar Competidor".
2. Ingresar datos personales.
3. Guardar información.
4. Confirmar registro.

---

 Caso de Uso 2: Crear Torneo

 Actor
Administrador

 Descripción

Permite crear un torneo seleccionando la modalidad de competencia.

 Flujo Principal

1. Crear torneo.
2. Ingresar nombre.
3. Elegir modalidad.
4. Agregar participantes.
5. Generar bracket.

---

 Caso de Uso 3: Registrar Resultado

 Actor
Administrador

 Descripción

Permite registrar el ganador de un enfrentamiento.

 Flujo Principal

1. Seleccionar encuentro.
2. Seleccionar ganador.
3. Guardar resultado.
4. Actualizar llaves del torneo.

---

 Caso de Uso 4: Consultar Bracket

 Actor
Administrador

 Descripción

Visualizar el estado actual del torneo.

 Flujo Principal

1. Seleccionar torneo.
2. Visualizar rondas.
3. Consultar enfrentamientos.
