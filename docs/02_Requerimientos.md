 Requerimientos del Sistema

 Requerimientos Funcionales

 RF01
El sistema debe permitir registrar competidores.

 RF02
El sistema debe permitir editar información de competidores.

 RF03
El sistema debe permitir eliminar competidores.

 RF04
El sistema debe permitir crear torneos.

 RF05
El sistema debe generar automáticamente brackets de eliminación directa.

 RF06
El sistema debe generar automáticamente brackets de doble eliminación.

 RF07
El sistema debe permitir registrar resultados de enfrentamientos.

 RF08
El sistema debe actualizar automáticamente las llaves del torneo.

 RF09
El sistema debe determinar automáticamente al campeón.

 RF10
El sistema debe almacenar el historial de torneos.

---

 Requerimientos No Funcionales

 RNF01
La aplicación debe ser fácil de utilizar.

 RNF02
Debe ejecutarse en dispositivos Android.

 RNF03
La información debe almacenarse de forma segura.

 RNF04
La interfaz debe ser intuitiva.

### RNF05
El tiempo de respuesta debe ser menor a 3 segundos.
